Optional: put a font here (.ttf, .otf or .ttc) and the game will use it instead of a system font.

By default the game looks for a font in this folder first, then falls back to well-known system fonts
(Segoe UI / Arial on Windows, Arial / Helvetica on macOS, DejaVu Sans / Liberation Sans on Linux).
Windows and macOS always have one, so you normally do not need to add anything.

If you bundle a font, make sure its licence allows redistribution (for example fonts under the SIL Open
Font License such as Open Sans, Roboto or DejaVu Sans) and ship its licence text next to it.
